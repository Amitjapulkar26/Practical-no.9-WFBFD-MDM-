## 📌 About The Project

**Personal To-Do List** is a simple web application designed to organize daily academic and personal tasks in one place.

The application demonstrates basic **JavaScript DOM manipulation** by dynamically creating, adding, updating and removing tasks.

---

## 🎯 Aim

To develop a Personal To-Do List application using:

- HTML
- Tailwind CSS
- JavaScript

The application allows users to:

- ➕ Add tasks
- ✅ Mark tasks as completed
- ❌ Delete individual tasks
- 🗑️ Clear all tasks

---

## ✨ Features

| Feature | Description |
|---|---|
| ➕ Add Task | Dynamically adds a new task |
| ✅ Complete Task | Marks a task as completed |
| ❌ Delete Task | Removes an individual task |
| 🗑️ Clear All | Removes all tasks |
| 🔢 Task Counter | Displays the current number of tasks |
| 📱 Responsive UI | Works on different screen sizes |
| 🎨 Clean Design | Simple and professional interface |
